# Password Strength Service

Сервис проверки устойчивости паролей.

## Назначение проекта

Веб-сервис для комплексной оценки надёжности паролей. Приложение рассчитывает энтропию и оценивает паттерны ввода с помощью zxcvbn, проверяет пароли по локальной базе утечек и через внешний API Have I Been Pwned (HIBP) по модели k-анонимности, а также формирует визуальную оценку сложности в реальном времени.

Проект разработан в рамках курсовой работы по дисциплине «Веб-программирование».

## Используемый стек технологий

- **Backend:** Python 3.11+, FastAPI
- **Frontend:** TypeScript / React, сборщик Vite
- **База данных:** Microsoft SQL Server (хранение дампов утечек и хэшей паролей)
- **Кэширование:** Redis (Bloom-фильтры для предварительного отсева, кэш частых запросов)
- **Оценка сложности:** zxcvbn-python, регулярные выражения
- **Контейнеризация:** Docker, Docker Compose
- **CI/CD:** GitHub Actions
- **Тестирование:** pytest (backend), Vitest (frontend)

## Архитектура

Сервис построен по клиент-серверной архитектуре с разделением на три независимых слоя.

### Слой клиента (SPA)
Одностраничное приложение на React, собираемое через Vite. Отвечает за ввод пароля, отправку запросов к API с механизмом debounce и визуализацию результатов — индикатор сложности и список предупреждений об утечках.

### Слой API (Backend)
Сервис на FastAPI, инкапсулирующий всю логику оценки:

- **Модуль оценки сложности** — расчёт энтропии, проверка по словарям и паттернам через zxcvbn, дополнительные регулярные проверки.
- **Модуль проверки утечек** — сравнение SHA-1/NTLM-хэшей с локальной базой утечек в SQL Server; предварительный отсев через Bloom-фильтры в Redis.
- **Модуль внешних проверок** — взаимодействие с HIBP Pwned Passwords API по схеме k-анонимности (наружу отправляется только префикс хэша, сам пароль не покидает сервер).

### Слой данных
- **Microsoft SQL Server** — хранение дампов утечек (RockYou, SecLists, Hashes.org) и служебных таблиц.
- **Redis** — Bloom-фильтры для быстрого отсева уникальных паролей и кэш результатов по часто проверяемым хэшам.
